# Demo Walkthrough

## 1. Dashboard

Review:

- certificate inventory;
- expiry risk;
- renewal queue;
- signing activity;
- infrastructure health;
- alerts.

## 2. Certificate request

Create a synthetic certificate request and observe policy validation and approval state.

## 3. Certificate inventory

Use filtering/search to inspect certificate metadata and lifecycle state.

## 4. Renewal

Review certificates approaching expiry and follow the renewal workflow.

## 5. Revocation

Demonstrate a controlled revocation operation and confirm that the lifecycle state changes and an audit event is produced.

## 6. Signing

Review signing-request controls and the HSM/Key Vault abstraction without exposing private-key material.

## 7. Audit

Review lifecycle events and evidence generated by operational actions.

## 8. Monitoring

Use system-health and event views to connect certificate/signing activity with reliability concerns.

All demonstration data must remain synthetic.
